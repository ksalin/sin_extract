# sin_extract
Pak file extractor for Sin Reloaded data files

The new remastered version of the game "Sin" called Sin Reloaded, which is available on steam, etc., has pak files with .sin extension but different format that before in the Sin games or in Quake. This python script can extract files from the pak files that are in the format of Sin Reloaded.

Just run sin_extract.py with python3 to get help.
